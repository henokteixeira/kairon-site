# kairon-tech.com

Site da Kairon Tech. Estático, servido pelo GitHub Pages no domínio kairon-tech.com.

- `index.html`: versão em inglês (padrão). Quem tem o navegador em português é levado para `/pt/`.
- `pt/index.html`: versão em português.
- `assets/`: favicons, imagem de compartilhamento e foto.

As páginas são geradas a partir de um script com os textos nas duas línguas, mantido junto com os arquivos da marca.
